# California Housing - Machine Learning
Machine learning analysis and prediction of California housing prices

## Project Overview

This project focuses on analyzing the California housing market
and building machine learning models to better understand and
predict house prices.

## Objectives

- Explore and preprocess the dataset
- Perform exploratory data analysis
- Analyze relationships between housing characteristics and prices
- Build and evaluate machine learning models
- Compare model performance

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Structure
- `California_Housing.ipynb` — Complete analysis and machine learning workflow
- `California_Houses.csv` — Dataset
- `california.png` — Geographic visualization
